## About Me

I'm a **Backend Software Engineer** focused on designing and building scalable, maintainable, and reliable backend systems.

- Specialized in **Backend Engineering** and RESTful API development.
- Interested in **Software Architecture, Distributed Systems, and Microservices**.
- Working with **TypeScript, Node.js, Go, Python, and Java**.
- Building backend solutions using relational and NoSQL databases such as **PostgreSQL, MySQL, MongoDB, and Redis**.

My goal is to build software that solves real-world problems through solid engineering practices, thoughtful architecture, and continuous learning.
